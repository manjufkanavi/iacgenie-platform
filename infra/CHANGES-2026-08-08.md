- `iacgenie.com` / `www.iacgenie.com` → landing page

- `*.iacgenie.com` → catch-all 404

**Fixed systemd service** — updated binary path from `/usr/bin/cloudflared` to `/usr/local/bin/cloudflared` and removed broken `--origincert` CLI flag (config file handles it).

## ⚠️ Known Issue: Cloudflare Origin Cert Missing

The Cloudflare origin certificate (`/home/mkanavi/.cloudflared/cert.pem`) was accidentally deleted from the VM. This prevents the tunnel from connecting to Cloudflare edge.

**To fix:**
```bash
ssh mkanavi@192.168.0.118
cloudflared tunnel login    # Requires Cloudflare account credentials
# This regenerates /home/mkanavi/.cloudflared/cert.pem
sudo systemctl restart cloudflared
sudo systemctl is-active cloudflared
```

The tunnel identity (`argotunnel.json`) still exists with valid `TunnelID` and `TunnelSecret` — only the origin cert needs to be regenerated.
